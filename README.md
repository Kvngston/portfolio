# Tochukwu Nwankwu — Portfolio

Personal portfolio site for **Tochukwu Nwankwu**, Software Engineer.

Live preview: open `index.html` in any browser.

## Stack

- Single static HTML file (no build step)
- Vanilla CSS with custom properties (dark / techy theme)
- Inter + JetBrains Mono via Google Fonts
- IntersectionObserver-based scroll reveals
- Downloadable CV PDF served alongside the page

## Structure

```
.
├── index.html                  # The site
├── Tochukwu_Nwankwu_CV.pdf     # CV (linked from Download CV button)
└── README.md
```

## Deploy

Drop the folder onto any static host — no build required.

**GitHub Pages**

1. Push this repo to GitHub.
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://kvngston.github.io/<repo-name>/`.

**Netlify / Vercel**

Drag the folder onto Netlify Drop, or run `vercel` in this directory.

## Local preview

```bash
# Python 3
python3 -m http.server 8000
# then visit http://localhost:8000
```
